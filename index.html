Overview

Perkenalkan, saya adalah seorang mahasiswa prodi Sistem Informasi yang memiliki minat pada Pemrograman Website dan Sains Data. Saya menyadari bahwa minat saya perlu diiringi dengan banyak belajar dan berlatih, untuk itu saya mencoba untuk tetap belajar baik melalui perkuliahan, bootcamp, YouTube, maupun artikel di internet.

Masih belum banyak proyek yang saya buat. Sebuah proyek yang pernah saya terima diantaranya adalah melakukan maintenance website Rumah Sains Indonesia berbasis WordPress menggunakan Elementor. Selain itu beberapa proyek yang berkaitan dengan tugas akhir dari kampus maupun capstone project dari sebuah program pelatihan juga pernah saya kerjakan.

Proyek tugas akhir yang saya kerjakan yaitu melakukan pemodelan untuk peramalan volume penumpang kereta api pada wilayah Jabodetabek, Jawa, dan Sumatera. Sementara itu capstone project berkaitan dengan Analisis Penjualan dan Inventaris. Detail mengenai ketiga proyek dapat dilihat di bawah:
